# NurunuruLiveStudio

unacastと連携してコメントを受け取って画面に画像を出したりするためのツール

## 思想と言うか発端
ニコニコとかの配信プラットフォームにある「ギフト機能」みたいなことをやりたいけど収益化とかしてないので気分だけでも味いたいね。

## 主な機能
### レス中の金額入力を検知して画像を表示
（がぞう）
レスの中に「\100」のように円マークから始まる数値を検出すると画面に画像を表示します。

### 登録単語を検知して画像を表示
（）
登録した単語を検出したら画像を表示することもできます。

### 棒読みちゃんへの連携機能
このアプリはunacastの棒読みちゃん連携機能を利用しており、本来棒読みちゃんへ送るメッセージを受信して画像を出すようにしていますが。棒読みちゃんへのメッセージを流すこともできるため、レス読みに棒読みちゃんを利用していても問題なく使えます。

## 使い方

### 1. ダウンロード＆起動
(がぞう)
このGitHubのページの右側にReleaseってところがあるのでそれをクリックするとReleaseページに移動します。　　
（がぞう）
Assetsをクリックして出てきたNurunuruLiveStudio.zipをクリックしてダウンロードしてください。　　


### 2. 設定ボタンの表示
ここに画像を添付する（ダブルクリック後に設定ボタンが表示された状態）
- 画面をダブルクリックすると、左上に設定ボタンが表示されます。
- もう一度ダブルクリックすると設定ボタンは非表示になります。


### 3. トリガー設定（イベント設定）を行う
（イベント設定画面全体がぞう）
`トリガー` ボタンからイベント設定画面を開きます。  
この画面では画像表示する条件（以下トリガー）と  
条件を満たしたときに表示する画像の設定（以下イベント）を設定します。

- 左側リスト
  - `トリガー追加` で トリガー を追加
  - 各トリガー行の `追加` で その条件を満たしたときのイベント を追加
  - 各トリガー行の `削除` で トリガー（と、それに紐づくイベント）を削除
  - 各トリガー行の `↑` `↓` でトリガーの手動並び替え
- EventData行
  - `複製` で同一内容を追加
  - `削除` で該当イベントを削除
- 右側編集欄
  - トリガー または イベント を選択すると対応する編集項目が表示されます。

#### トリガー設定項目
(がぞう)
- eventType：画像表示の条件を設定、Wordで単語を条件に画像表示。Amountで金額を条件にする。
- Word：eventTypeをWordにしたとき設定可能。画像表示条件となる単語を設定する。日本語入力時の挙動がなんかおかしいのは許して。
- Amount：eventTypeをAmountにしたとき設定可能。画像表示条件となる金額を設定する。
- findType：eventTypeをWordにしたときのみ有効。レス中の単語の検索条件を設定する。基本はPartialでOK.
  - Partial：部分一致
  - Perfect：レス内容と登録単語が完全一致
  - Prefix：レスの先頭が登録単語と一致
  - sufix：レスの最後が登録単語と一致

#### イベント設定項目
（がぞう）
- path：表示する画像のパス、下の「ファイル選択」ボタンでファイルブラウザから選択可能。
- prefabType：上から落ちてくるタイプか画面の任意の位置に表示するタイプか選べる。
  - FallSprite：上から落ちてくるタイプ
  - MoveSprite：任意位置に表示
- lifeTime：画像表示時間、単位は秒、だったはず。
- size：画像サイズ。元の画像サイズを1とする。
- posX：基本空で良い。MoveSpriteでのみ設定可能。画像表示時のX座標で-1.0～1.0ぐらいで指定する。0で中心。空でランダム位置に表示。
- posY：基本空で良い。MoveSpriteでのみ設定可能。画像表示時のY座標で-1.0～1.0ぐらいで指定する。0で中心。空でランダム位置に表示。
- movX：基本空で良い。X軸の移動量。1でありえん速度で動くので入力するなら小数点以下の値で。
- movY：基本空で良い。Y軸の移動量。1でありえん速度で動くので入力するなら小数点以下の値で。

#### トリガー設定の保存
- `保存` ボタンで保存します。
- 未保存のまま `閉じる` を押した場合は確認ダイアログが表示されます。保存せずに閉じると設定変更が反映されないので注意。

### 4. 環境設定を行う
（環境設定画面画像）
`環境` ボタンから環境設定画面を開きます。
レス読み上げに棒読みちゃんを使っていない人は「棒読みちゃんへの転送」をOFFにしておいてください。

- 設定可能項目
  - 受信ポート番号（既定: 50002）
  - 転送ポート番号（既定: 50001）
  - 棒読みちゃんへの転送（ON/OFF）
- `保存` ボタンで保存します。

### 5．OBS取り込み
![OBS設定画面](/document/Readme用画像/5_OBS設定.jpg)
OBSのゲームキャプチャで「NurunuruLiveStudio」を選択して
「透過を許可」チェックボックスにチェックを入れてください。

### 6．unacast設定
![unacast設定画面](/document/Readme用画像/6_unacast設定.jpg)
unacastの読み子設定で、棒読みちゃんを選択し、
**待ち受けポートを50002に変更します。**

### 7．実行
（実行画面）
unacastでサーバー起動し、受信したレスに設定した単語があれば画面に画像が表示されます。

（金額）
トリガー設定で金額を設定した場合は、レスの文中に「￥100」のような円マーク（全角/半角どちらでも可）から始まる数字があった場合、設定したトリガーで一番金額が高いものが表示されます。  

（例：￥100、￥500、￥1000、のイベントを設定した状態で「おつかれ￥700」のようなレスが来た場合は￥500に設定された画像が表示されます。）

### 8．その他

- 要望とかバグ報告は[issues](https://github.com/yudeunagi/NurunuruLiveStudio/issues)に投げるか配信してる時に言ってちょ。
- セーブファイルはC:\Users\｛username｝\AppData\LocalLow\DefaultCompany\NurunuruLiveStudioにあるはず。
- config.jsonが環境設定で、triggerData.jsonがトリガーデータの設定ファイルです。
