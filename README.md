# NurunuruLiveStudio

## 概要

unacastと連携してコメントを受け取って画面に画像を出したりするためのツール

## 基本仕様

TestTCPServerクラスでは指定された待ち受けポートでメッセージの待ち受けを行い、別のポートに手受信したメッセージを出力する。このポートは設定で変更可能である。

メッセージに特定文字列が含まれている場合、文字に応じた画像を画面に表示させる。

- 待ち受けポート = 50002（設定で変更可能）
- 送信ポート = 50001（設定で変更可能）

## メッセージに含まれる特定文字の判定について

SuperChatManagerクラスとTriggerManagerクラスにてメッセージの判定を行う。

SuperChatManagerクラスでは、金額を表す"\"から始まる数字を抽出し、金額に応じたイベントを起動する。

TrrigerMnagerクラスではメッセージに含まれる特定文字列を抽出し、文字に応じたイベントを起動する。
