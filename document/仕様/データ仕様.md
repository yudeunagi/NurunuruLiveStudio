# データ仕様
- triggerDatas：
  - id：自動的に採番されるID
  - type：メッセージ内に含まれる金額を参照するか、単語を参照するかを決める("amount" or "word")
  - amount：イベントを起動させるトリガーとなる金額
  - word：イベントを起動させるトリガーとなる単語
  - sound：再生する音声に関するデータで子要素を持つ
    - path：再生する音声ファイルのパス
    - volume：音量
  - event：実行するイベントで複数の要素を持つリスト
    - id：イベントのID、自動的に採番される
    - path：表示する画像ファイルのパス
    - prefabType：生成するUnityのPrefab名を指定する
    - parameters：この要素の子要素に生成したPrefabに適用する各種パラメーターを記載する
      - lifeTime：オブジェクトの生存時間
      - size：オブジェクトサイズ
      - posX：生成時のX座標
      - posY：生成時のY座標
